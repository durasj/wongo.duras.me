# Wongo - tačustav edition 2026

Development branch: `wongo-tacustav-edition-2026`.

This edition starts from the verified Wongo game. Its title appears in the application, browser metadata, printed cards and bilingual rulebook headers. `src/data/edition.json` is the edition identity source.

The user supplied Tačustav reference posters on 25 October 2026: a playful family renovation theme with distressed plaster, black brush-stroke panels, bold condensed lettering, construction tools, a hard-hat dog mascot, and Slovak family jokes. These references guide future edition artwork; the full visual treatment is not implemented yet. Keep illustrations outside the functional puzzle grids.

The confirmed purchased filaments are Flashforge PLA Matte, 1.75 mm: **Mango Yellow** (IDs 01–04), **Blue (072C)** (05–08), **Red** (09–12), and **Mint Green** (13–16). This palette is implemented in the canonical catalogue and downloadable manifest; see `docs/PIECES.md` for the print quantities and screen approximations. Use these four colours consistently for pieces, cards and solutions; poster accent colours must not redefine piece groups.

Preserve the 16 shapes, physical dimensions, inventory counts, puzzle codes and verified solutions. Edition artwork must leave the actual-size puzzle grids, piece IDs, calibration marks and solution diagrams legible. Use the same generators and regression checks as the base game.
